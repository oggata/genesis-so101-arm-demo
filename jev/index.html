コマンド一覧 / JS API 
move_to X Y Z [PITCH]   グリッパー先端(TCP=爪の中心)を (X,Y,Z)cm へ。PITCHは手先の向き(deg, 既定 -90=真下)
move_by DX DY DZ        現在のTCPから相対移動(cm)
joint NAME DEG          関節を絶対角度へ   例: joint wrist_roll 45
nudge NAME DEG          関節を相対回転     例: nudge shoulder_pan -10
joints A B C D E [G]    5関節(+グリッパー)をまとめて指定
gripper PCT             0=閉 〜 100=全開
open / close            グリッパー全開 / 全閉（物体があればそこで止まる）
home                    初期姿勢へ
reset [SEED]            キューブを再配置
speed DEG_PER_S         関節の最大速度（既定 60）
wait MS                 待機
state                   状態をログに出力
help                    このヘルプ

関節名: shoulder_pan, shoulder_lift, elbow_flex, wrist_flex, wrist_roll, gripper
キューブ: 一辺 2.5cm（中心の高さ z=1.25）。トレイに入れると "in tray" に表示される。
